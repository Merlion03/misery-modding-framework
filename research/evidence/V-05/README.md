# V-05 — версия IoStore TOC и форма 144-байтного заголовка

Метод `plan.md` §4.1 V-05. Инструмент — `tools/static/engine_version.py`; смещения полей
берутся из `TOC_HEADER_FIELDS` в `tools/fingerprint/container_info.py` (F-02), той же
таблицы, которой заголовок разбирает F-02, — поэтому два инструмента не могут разойтись
в том, где лежит байт версии.

| Файл | Что это |
|---|---|
| `toc-header-reads.json` | по каждому `.utoc` установки: совпадение магии, версия, `toc_header_size`, флаги контейнера, число методов сжатия и два буквальных чтения класса P — байт версии (offset 16, длина 1) и размер заголовка (offset 20, длина 4) |

Байт версии TOC меняется между минорными релизами UE5, и потому это различитель, а не
проверка на согласованность. Оба контейнера установки читаются независимо и дают одно и
то же значение. Соответствие «версия TOC → релиз UE» —
`research/evidence/V-06/external-reference.md`.

Ничего не расшифровывалось (D-02): читается только заголовок, который лежит открытым.
Directory index основного контейнера зашифрован и не открывался — это уже зафиксировано
в `fingerprint.json` и здесь не повторяется как отдельное утверждение.
